# تشغيل المشروع

مدير جلسات واتساب يُتحكم به عبر بوت تليجرام. مبني على `grammy` + `@whiskeysockets/baileys`.

---

## المتطلبات

- **Node.js 20 أو أحدث** (مطلوب من Baileys)
- npm

---

## التثبيت والتشغيل

### 1. ثبّت التبعيات

```bash
npm install
```

### 2. جهّز الإعدادات

```bash
cp .env.example .env
```

ثم افتح `.env` واملأ القيمين المطلوبتين:

```env
TELEGRAM_BOT_TOKEN=123456:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
OWNER_ID=6707747395
```

- **التوكن** من [@BotFather](https://t.me/BotFather) (`/newbot`)
- **المعرف** الرقمي حقك في تليجرام — مو اسم المستخدم. تحصل عليه من `@userinfobot`

### 3. تحقق من الإعدادات

```bash
npm run config:check
```

### 4. افحص اتصال واتساب

```bash
npm run doctor
```

هذه الخطوة **مهمة قبل أول تشغيل** — تخبرك بالسبب الدقيق لو فشل الربط بدل رسائل غامضة.

```bash
npm run doctor -- --pair 628123456789   # مع طلب كود ربط
npm run doctor -- --keep                # لا يحذف مجلد الفحص المؤقت
```

### 5. شغّل

```bash
npm start
```

## 🎛 لوحة التحكم

أرسل `/panel` للبوت في الخاص (المالك والراسيلرز فقط).

| القسم | ما يوفّره |
|---|---|
| 🏠 الرئيسية | نظرة عامة: الجلسات، المستخدمون، الوضع الحر، الكولدون، الأخطاء، الذاكرة، مدة التشغيل |
| 📱 الجلسات | عرض كل جلسة وحالتها، قطع الاتصال، إعادة الوصل، حذف جلسة، حذف الكل (بتأكيد) |
| 👥 المستخدمون | **بطاقة لكل مستخدم**: منح/إلغاء الوصول، ترقية/تنزيل راسيلر، تصفير كولدونه، مراسلته، حذفه · + الوصول/الراسيلرز/المحظورون/البيضاء مع ترقيم الصفحات |
| ⚙️ الإعدادات | الوضع الحر، وضع الصيانة، + **إعدادات متقدمة**: حد الطلبات، أقصى جلسات، الكولدون الافتراضي، الحماية من التكرار، إعادة الاتصال التلقائي |
| ⏱️ الكولدون | تفعيل/تعطيل، **قائمة المستخدمين عليهم كولدون** مع تصفير فردي، إعادة تعيين الكل، الحالة |
| 📢 البث | رسالة جماعية للجميع أو لأصحاب الوصول — **معاينة + تأكيد** قبل الإرسال، ونتيجة بعده |
| 📜 اللوقات | آخر 200 حدث داخل تليجرام مع عدّ الأخطاء والتحذيرات |
| 📊 الإحصائيات | أرقام تفصيلية |
| 🔧 الصيانة | تنظيف الكاش، إعادة تشغيل آمنة (تغلق الجلسات أولًا) |

**ملاحظات تقنية:**
- كل الأزرار تستخدم النطاق `ap:` فلا تتعارض مع أزرار البوت الأصلية
- كل الأفعال الخطيرة (حذف، إعادة تشغيل) تطلب **تأكيدًا** أولًا
- اللوحة **لا تحتوي أي زر يشغّل أوامر الكراش/السبام** — هي إدارة فقط
- كل الأفعال الحسّاسة تمرّ بخطوة تأكيد قبل التنفيذ
- حدّ تليجرام (64 بايت لـ `callback_data`) مُختبَر آليًا على كل الأزرار

## مستويات اللوق

في `.env`:

```env
LOG_LEVEL=info      # افتراضي
LOG_LEVEL=debug     # عند تشخيص مشاكل الاتصال
LOG_LEVEL=silent    # إسكات تام
```

> القديم كان `silent` دائمًا ومكتوب حرفيًا في الكود — كان يخفي سبب فشل الاتصال تمامًا.

## ملاحظات أمنية مهمة

1. **لا ترفع ملف `.env` أبدًا** — مستثنى في `.gitignore`
2. **لا ترفع مجلد `session/`** — فيه مفاتيح تشفير واتساب
3. لو انكشف التوكن في أي وقت: `@BotFather` → `/revoke`
4. الأوامر `/settoken` و`/setconfig` **مُعطّلة عمدًا** — كانت تعدّل الكود المصدري أثناء التشغيل
